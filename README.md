## Descrição do Projeto
Este projeto é um aplicativo mobile desenvolvido em **React Native + Expo** que simula um painel de controle e monitoramento de uma missão espacial. O sistema fornece uma interface temática e funcional para acompanhar a telemetria da espaçonave, garantindo estabilidade e resposta rápida a possíveis incidentes.

## Tecnologias e Funcionalidades Implementadas
O sistema foi projetado de forma modular e conta com as seguintes ferramentas e recursos:
* **Dashboards Reativos:** Monitoramento em tempo real de sensores, energia, comunicação e estabilidade orbital.
* **Alertas Automáticos:** Notificações disparadas imediatamente caso os parâmetros da nave atinjam níveis críticos.
* **Expo Router:** Roteamento de telas baseado em arquivos (File-based routing).
* **Context API:** Gerenciamento de estado global para compartilhamento de dados simultâneo entre as telas.
* **AsyncStorage:** Persistência de dados local, garantindo que as configurações da missão não sejam perdidas ao fechar o app.
* **Formulários Validados:** Telas de entrada de dados com verificação de campos obrigatórios, limites numéricos e formatos.
